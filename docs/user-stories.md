# Implemented user stories

- As a user, I can sign in and sign out.
- As a user, I can view products in alphabetical pages of 10.
- As a user, I can see a product's ID, name, and quantity.
- As a user, I can add a product with a non-blank name and quantity of at least 1.
- As an API consumer, I can create and list products through a JWT-protected gateway.
